## 👋 About Me

I'm **Thamsanqa Hadebe** (aka `BhunganeCodes`), a self-driven developer from South Africa 🇿🇦 on a mission to break into Data Science and AI/ML Engineering.

I'm passionate about using data to solve real problems — whether that's analysing trends, training predictive models, or building intelligent systems that actually work in the wild. My background spans full-stack development and I'm deepening my skills in machine learning, deep learning, and data analysis every day.
